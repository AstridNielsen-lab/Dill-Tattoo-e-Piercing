# Dill Tattoo e Piercing

Bem-vindo ao Template do **Dill Tattoo e Piercing**! Este projeto é o site oficial do estúdio, onde oferecem tatuagens personalizadas, aplicação profissional de piercings e barbearia especializada.

## Funcionalidades

- **Home Page**: Apresentação principal do estúdio e serviços.
- **Serviços**: Descrição detalhada dos serviços oferecidos (tatuagem, piercing e barbearia).
- **Galeria**: Exibição de imagens dos trabalhos realizados para inspirar os visitantes.
- **Depoimentos**: Seção com comentários de clientes sobre os serviços.
- **Contato**: Informações para contato direto com o estúdio, incluindo localização, telefone e redes sociais.

## Como Usar

1. Clone este repositório:
   ```bash
   git clone https://github.com/seu-usuario/dill-tattoo.git
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Inicie o servidor localmente:
   ```bash
   npm start
   ```

4. Acesse o site no navegador:
   ```bash
   http://localhost:3000
   ```
